# Caderno Temático - DevSecOps.

Este projeto consiste na criação de um caderno temático no NotebookLM, utilizando fontes abertas sobre DevSecOps.

Acesso ao caderno no NotebookLM através do link [https://notebooklm.google.com/notebook/270b3ac7-a375-4ae8-ae3d-fcbceee880bc](https://notebooklm.google.com/notebook/159e303b-cd73-43af-8402-4b7fa5431f2f)

Conteúdos desenvolvidos:

- Curadoria de fontes
- Objetivos de estudo
- Perguntas estratégicas
- Testes de prompts
- Resumos e apresentação
